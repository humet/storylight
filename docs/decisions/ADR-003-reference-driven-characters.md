# ADR-003: Reference-Driven Character Identity

**Status:** Accepted

## Context

Prompt-only character descriptions produce visual drift.

## Decision

Represent each child-character with an approved, versioned visual profile and reference assets. Every persistent-character illustration uses approved references.

## Consequences

- Character setup requires parent approval.
- Images need reference-aware providers.
- Visual profiles are pinned per series.
- Identity review is a blocking publication gate.
- Child photographs are not required for the MVP.
