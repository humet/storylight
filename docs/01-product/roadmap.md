# Storylight Roadmap

## Phase 0 — Foundations

- Repository setup
- Documentation and ADRs
- Domain types
- Database schema
- Private object storage
- Authentication boundary
- Model adapters
- Workflow execution and observability

Exit criterion: a synthetic end-to-end workflow can persist a planned story, chapter, continuity state, and placeholder illustration records.

## Phase 1 — Character foundation

- Family and child-character records
- Visual profile creation without photographs
- Candidate generation
- Parent approval
- Reference asset versioning
- Default outfits

Exit criterion: two persistent characters can be created, approved, and reused in test image prompts.

## Phase 2 — One-off stories

- Mobile story-creation flow
- One-off planning
- Story writing
- Review and revision
- Illustration planning
- Mobile reader
- Regeneration

Exit criterion: a parent can create and read a safe illustrated one-off story on a phone.

## Phase 3 — Series

- Series bible
- Chapter blueprints
- Next-chapter workflow
- Continuity snapshots
- Plot-thread state
- Series library and progress
- Restricted regeneration after later chapters exist

Exit criterion: a five- or ten-chapter series can be completed without critical continuity failure.

## Phase 4 — Illustration quality

- Art Bible
- Location references
- Vision review
- Targeted repair
- Premium escalation
- Responsive derivatives
- Visual regression dashboard

Exit criterion: approved identity thresholds are met across the image evaluation set.

## Phase 5 — Product hardening

- Accessibility review
- Offline resilience
- Error recovery
- Cost budgets
- Provider fallbacks
- Evaluation dashboard
- Canary rollout
- Operational alerts

Exit criterion: production readiness checklist passes.

## Later possibilities

- Narration
- Family voice recording
- Printable books
- Additional approved art styles
- Shared recurring worlds
- Multilingual stories
- Parent-authored edits
- Seasonal collections
- Collaborative prompts from siblings

## Explicitly deferred

- Public social profiles
- Child-to-child messaging
- Mandatory photo avatars
- Infinite feeds
- Autonomous choose-your-own-adventure
- Custom model fine-tuning
- Public prompt marketplace
