# Storylight Vision

## Mission

Storylight helps families create magical bedtime traditions through beautifully illustrated, personalised stories.

It is not a general AI assistant and should not feel like a chatbot. The interface should feel like opening a private family library of storybooks.

## Vision statement

The intended response from a child is:

> “Can we read the next chapter tonight?”

—not—

> “Can we generate something else?”

Storylight succeeds when families remember the stories and the shared ritual, not the technology used to create them.

## Product pillars

### Exceptional storytelling

Stories need structure, emotional movement, memorable detail, and satisfying endings. Series must know where they are going before they begin.

### Recognisable characters

Children should immediately recognise their Storylight characters in every illustration. Appearance, personality, relationships, and long-term history must remain consistent.

### Persistent worlds

Favourite places, companions, magical objects, and inside jokes should be able to return. Familiarity is a feature.

### Effortless creation

A parent should be able to start from a single idea. The system handles planning, continuity, safety, illustration selection, and quality control.

### Trust

Parents must be able to rely on Storylight at bedtime. Safety, age appropriateness, calm endings, and predictable quality are product requirements.

## Emotional goals

Children should feel some combination of:

- safe
- curious
- delighted
- brave
- understood
- eager to return tomorrow

Parents should feel:

- relaxed
- in control
- confident in the content
- connected with their children
- pleased with the quality

## What Storylight is not

Storylight is not:

- an infinite content feed
- a social network
- a game designed to maximise screen time
- a public children’s profile platform
- a replacement for books
- an educational worksheet generator
- an autonomous AI agent

## Guiding question

When product priorities conflict, ask:

> Will this help create a bedtime memory that a family will treasure?

If not, simplify or remove it.
